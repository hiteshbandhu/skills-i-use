# Carousel principles

## Structure
| Slide | Job | Rule of thumb |
|---|---|---|
| 1 Hook | stop the scroll, make them swipe | 1–3 huge words, a striking visual, a swipe cue (arrow, "swipe ->") |
| 2…n-1 Beats | build momentum, one idea each | same type system, the colour changes per slide, one sticker or visual per beat |
| n CTA | one action | restate the promise in 2–4 words, one button-like CTA (pill), brand line small |

- 5–8 slides beats 15. Each slide should earn the next swipe.
- Sequence copy as a sentence or chant across slides ("LOG OFF / PICK UP A BOOK / BRING A PEN …"). Rhythm makes people swipe to finish it.
- The hook must make sense standing alone, because it's the only slide most people see.

## The CTA
- Pick one: comment a keyword (best for reach and DMs), save, share, DM, link in bio.
- Make it a pill or button shape, the highest-contrast element on the slide, legible at 200 px wide.
- Comment-keyword CTAs work best with automated DM replies. Remind the user to set one up or reply by hand.
- Repeat the CTA in the caption's first line.

## Layout
- Canvas 1080×1350. Keep text inside x 80–1000, y 100–1250. Instagram's UI covers the bottom edge in some views.
- Treat the deck as one panorama: elements crossing seams (torn paper, tape, a long sticker) create continuity. Never cut a word or a face at a seam.
- Headlines: condensed heavy type sized to the width (`fit_w`), slight rotations (±3°) for a hand-made feel.
- Flat bold background per slide, plus paper grain (0.05–0.08) and halftone patches, so it feels printed, not templated.
- Stickers: white border 14–20 px, soft drop shadow, rotation ±3–10°; cut-outs of objects and hands are great fillers that don't feature any one person.

## Real people
- Each person appears once, at a similar size, unless the brief says otherwise.
- No type, tape or bubbles over faces.
- Remove anyone who asked to be removed from every slide, and check all stills.
- No captions that put words in a real person's mouth.

## QA checklist
- [ ] Hook works alone at feed size
- [ ] Every seam has a continuity element, and nothing important is cut
- [ ] No headline is overlapped by another element
- [ ] CTA is legible on the sheet thumbnail
- [ ] No full stops in headlines
- [ ] All assets are owned, licensed or user-provided
