# Run Summit 2023 workshops

Workflow playbooks from four AI Engineer Summit 2023 workshops: foundations, inference, product patterns, and prompt engineering.

## Usage

```
@run-summit-2023-workshops onboarding plan for new AI engineers
help us scope inference-as-a-service
apply Karina's prompt principles to our support bot
```

## What it does

- Routes you to **4 workflows** (101 → inference → Rest of the Owl → prompts)
- Step-by-step actions with citations to workshop learnings
- Agent deliverables and stop conditions per workflow
