# Build multimodal products

Six AIEWF 2024 multimodality talks as product/engineering workflows.

Output: `./skill-outputs/build-multimodal-products/` (checklists, rubrics, diagrams when you run a workflow).

## Usage

```
@build-multimodal-products design voice agent under 500ms
multimodal UX without form fields
```

## What it does

- Routes you to workflows **A–F**
- Step-by-step actions with citations to source talks
- Agent deliverables and stop conditions per workflow

## Files

```
build-multimodal-products/
├── SKILL.md
├── README.md
├── workflows.md
└── source-index.md
```
