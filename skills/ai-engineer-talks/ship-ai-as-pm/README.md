# Ship AI as PM

Nine AI PM World's Fair talks as shipping and strategy workflows.

Output: `./skill-outputs/ship-ai-as-pm/` (checklists, rubrics, diagrams when you run a workflow).

## Usage

```
@ship-ai-as-pm AI product strategy for crowded market
roadmap when we dont know model limits
```

## What it does

- Routes you to workflows **A–I**
- Step-by-step actions with citations to source talks
- Agent deliverables and stop conditions per workflow
