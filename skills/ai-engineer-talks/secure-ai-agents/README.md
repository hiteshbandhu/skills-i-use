# secure-ai-agents

Actionable security workflows distilled from eleven **Security @ AI Engineer** talks (OAuth, agent red teaming, CIAM, sandboxes, bots, fuzzing, Azure PyRIT, PCC patterns).

## Install

```bash
cp -r skills/secure-ai-agents ~/.cursor/skills/
cp -r skills/secure-ai-agents ~/.codex/skills/
cp -r skills/secure-ai-agents ~/.claude/skills/
```

From [skills-i-use](https://github.com/hiteshbandhu/skills-i-use) or this repo after sync.

## Invoke

```
@secure-ai-agents harden our MCP agent OAuth and token exchange
@secure-ai-agents red-team checklist before we ship this coding agent
```
