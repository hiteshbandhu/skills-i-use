# Learn Summit 2023 remote talks

Eleven remote-session playbooks from AI Engineer Summit 2023: evals, hybrid RAG, model selection, prompts, multimodal apps, maturity models, and career paths.

## Usage

```
@learn-summit-2023-remote eval harness for our chatbot
design hybrid context queries for grounding
map our coding agent to the maturity model
```

## Files

- `SKILL.md` — decision tree
- `workflows.md` — workflows A–K
- `source-index.md` — talk map

## Install

```bash
cp -r learn-summit-2023-remote ~/.cursor/skills/
```
